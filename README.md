## 🌌 Tentang Proyek

**AkazaWebsiteV2** adalah proyek website pribadi yang mengusung tema anime dengan nuansa gelap dan tampilan visual yang menarik.

Proyek ini dibuat sebagai sarana belajar, bereksperimen dengan desain antarmuka, dan mengembangkan keterampilan pemrograman web menggunakan teknologi front-end.

## ✨ Fitur

- 🎨 Desain bertema anime dengan nuansa gelap.
- 🎬 Penggunaan media gambar dan video.
- 💻 Dibangun menggunakan HTML, CSS, dan JavaScript.
- ⚡ Struktur kode front-end yang sederhana.
- 🌐 Dapat dijalankan melalui browser.

## 🛠️ Teknologi yang Digunakan

| Teknologi | Kegunaan |
|---|---|
| HTML5 | Membuat struktur halaman website. |
| CSS3 | Mengatur tampilan, warna, animasi, dan tata letak. |
| JavaScript | Menambahkan fungsi dan interaktivitas website. |

## 🚀 Cara Menjalankan Proyek

### 1. Clone repository

```bash
git clone https://github.com/gyzeennnpro-sudo/akazawebv2.git
```

### 2. Masuk ke folder proyek

```bash
cd akazawebv2
```

### 3. Jalankan website

Buka file `index.html` menggunakan browser.

Kamu juga dapat menggunakan ekstensi **Live Server** di Visual Studio Code untuk menjalankan website selama proses pengembangan.

## ✨ Fitur

- ⚔️ **Hero Karakter** — Menampilkan karakter dengan video latar dan teks animasi.
- 🎬 **Galeri Visual** — Galeri gambar bergerak dengan tampilan dinamis.
- 🔥 **Bagian Duel** — Pengalaman scroll horizontal untuk menampilkan pertarungan karakter.
- 🎞️ **Animasi Sinematik** — Efek scroll, parallax, penghitung statistik, dan animasi interaktif menggunakan GSAP.
- 📱 **Desain Responsif** — Tata letak yang menyesuaikan desktop dan perangkat mobile.
- ♿ **Reduced Motion** — Mendukung preferensi `prefers-reduced-motion` untuk mengurangi animasi sesuai pengaturan perangkat.

## 🧰 Teknologi

| Teknologi | Kegunaan |

## 🚀 Cara Menjalankannya

Proyek ini menggunakan HTML, CSS, dan JavaScript biasa sehingga tidak memerlukan proses build atau instalasi paket khusus.

### 1. Clone Repository

```bash
git clone https://github.com/gyzeennnpro-sudo/akazawebv2.git
```

### 2. Masuk ke Folder Proyek

```bash
cd akazawebv2
```

### 3. Jalankan Website

Buka file `index.html` menggunakan browser.

Untuk pengalaman pengembangan yang lebih konsisten, gunakan ekstensi **Live Server** di Visual Studio Code.

Alternatifnya, jika Node.js sudah terpasang, jalankan server lokal menggunakan:

```bash
npx serve .
```

Kemudian buka alamat lokal yang ditampilkan di terminal.

> 💡 **Catatan:** Koneksi internet diperlukan untuk memuat GSAP dari CDN dan Google Fonts jika digunakan oleh website.
